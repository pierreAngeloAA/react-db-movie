🎬 DbMovie — Descripción de proyecto

DbMovie es una aplicación web construida con React y The Movie Database (TMDb API) que permite a los usuarios:

Buscar películas por nombre.

Explorar listados de películas populares y mejor valoradas.

Guardar películas en su lista de favoritos.

Ver detalles de cada película en un modal (poster, overview, rating, etc).

🚀 Objetivos iniciales

Configuración de proyecto con Vite + React + Bootstrap.

Implementar un componente principal MovieExpertApp.

Crear componentes reutilizables (Navbar, MovieList, MovieCard, Modal).

Integrar hooks personalizados (useMovies, etc.) para el manejo de la API.

Añadir gestión de favoritos con localStorage.

Mejorar la experiencia con loading states y manejo de errores.

📌 Futuras mejoras

Filtros por géneros.

Paginación infinita.

Autenticación de usuarios (favoritos en la nube).

Responsive design completo.
